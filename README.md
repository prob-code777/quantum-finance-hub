# 🚀 Quantum Hub | Premium Quantitative Terminal v3.0

**Quantum Hub** is an institutional-grade financial analytics platform built with **Apple's Liquid Glass UI** philosophy. It provides real-time market data, automated buy/sell signals, and advanced portfolio management capabilities directly in the browser.

## ✨ Premium Features

- **💎 Liquid Glass UI**: Ultra-premium interface inspired by the latest Apple design language, featuring mesh gradients, frosted glass effects, and smooth animations.
- **📊 Institutional Universe**: Embedded database of 150+ major instruments across Italy (FTSE MIB), USA (Nasdaq/S&P), Crypto, and Global ETFs.
- **⚡ Real-time Market Data**: Live price streaming and change tracking via high-speed financial APIs.
- **🧠 Quantum Signals Scanner**: Automated buy and sell signals based on momentum and volatility scoring.
- **📈 Advanced Analysis Modal**: Integrated TradingView charts with custom technical indicators for every asset.
- **💼 Portfolio & Watchlist**: Personalize your terminal with a persistent watchlist and real-time portfolio tracking.

## 🛠 Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Lucide Icons, Day.js
- **Data Engine**: Yahoo Finance API (via CORS Proxy)
- **Charting**: TradingView Advanced Charts
- **UI Architecture**: Glassmorphism v2.0 (Liquid Glass)

## 🚀 Getting Started

The platform is fully standalone and can be deployed directly via GitHub Pages.

1. **Live Demo**: [Quantum Hub Terminal](https://prob-code777.github.io/quantum-finance-hub/)
2. **Search**: Use the global search to find any ticker or ISIN.
3. **Signal Scanner**: Click on "Buy Signals" or "Sell Alerts" to filter the market automatically.
4. **Analysis**: Click on any asset row to open the professional grade analysis workspace.
